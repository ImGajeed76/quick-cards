# Chrome Web Store assets

Source-of-truth copies of the text and assets that ship in the QuickCards
Chrome Web Store listing. Edit here, then paste into the Web Store Developer
Dashboard.

## Files

- `listing.md`: title, descriptions, single purpose, category
- `permission-justifications.md`: per-permission and per-host justifications, plus the remote-code answer
- `privacy-disclosures.md`: privacy-practices form answers, certifications, contact, distribution
- `screenshots/`: store screenshots and promo tile (forthcoming)
